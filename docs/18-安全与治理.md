# 18. 安全与治理

## 18.1 SSRF 防护：`SsrfGuard`

所有"用户可给 URL"的出站点统一过 `SsrfGuard.validateURLForSSRF`（`platform/.../security/SsrfGuard.java`；主码中 49 个文件引用，覆盖：模型调用 `LlmTransport` / `EmbeddingHttp`、网页抓取 `websearch` 的 `Fetcher` / `SearchHttp`、IM 各渠道客户端、存储 provider（`S3CompatibleFileService` / `TosFileService` / `OssFileService` 等）、数据源连接器（`NotionClient` / `RssClient` / `ImaClient`）、MCP（`McpHttp` / `McpServiceUrls`）、OIDC 端点、检索引擎各向量库 REST 客户端、知识库图片引用 `RemoteImageRefs`）。策略：

- scheme 白名单 `http/https/ws/wss`（白名单只放宽主机/IP，**不放松 scheme**；wss 是 IM 长连接刚需）；
- 受限主机名（`localhost`、`127.0.0.1`、云 metadata 主机、`host.docker.internal`、`kubernetes*`）与受限后缀（`.local`/`.internal`/`.corp` 等 9 个）；
- 禁止直连 IP 与 IP 混淆形态（八进制/十六进制/十进制整数/IPv6 映射等 9 个正则）；
- DNS 解析后**任一**解析 IP 非公网即拒绝；受限端口黑名单（`22/23/25/445/3389/5432/3306/6379/27017/9200/2379/2380/8500/4001`）；
- 白名单支持精确域名 / `*.` 通配 / IP / CIDR（含解析后 CIDR 匹配）。两个来源：env `SSRF_WHITELIST` + `SSRF_WHITELIST_EXTRA`（启动期由 `RuntimeSnapshotWiring` 安装）+ 系统设置**运行期推送**（`SystemSettingService` 调 `reloadWhitelist` 原子替换）。
- 拒绝时抛 `SsrfException`；`formatSSRFError` 生成中文运维提示（提示在 `SSRF_WHITELIST_EXTRA` 加主机，示例 `SSRF_WHITELIST_EXTRA=<host>,*.example.com,10.0.0.0/8`）。

## 18.2 凭据加密：AES-256-GCM + `enc:v1:`

`CryptoService`：算法 `AES/GCM/NoPadding`（GCM tag 128 bit，12 字节随机 nonce），密钥取 env `SYSTEM_AES_KEY`，**必须恰好 32 字节**否则视为未配置（加密变 no-op、解密遇密文 strict 模式抛 `IllegalStateException`）。密文格式 `enc:v1:` + base64url(`nonce`||`ciphertext`)；无前缀视为历史明文原样返回，因此启用加密不需要停机迁移，存量行在下次写回时自动转密文。

| 落点 | 机制 |
|---|---|
| 租户配置列 `web_search_config` / `parser_engine_config` / `storage_engine_config` | `SecretJsonTypeHandler`：写前逐字段加密、读后逐字段解密，JSON 结构不变 |
| 模型参数 `apiKey` / `appSecret` | `ModelParametersTypeHandler` |
| MCP、IM、向量库连接配置 | `McpSecretTypeHandler` / `McpAuthConfigTypeHandler`、`ImCredentialsTypeHandler`、`ConnectionConfigTypeHandler` |
| 租户/平台 API Key 明文列、外部用户 HMAC 密钥 | `TenantAPIKeyRepository`、`APIPrincipalConfigTypeHandler` |
| 数据源凭据 | `DataSource` / `DataSourceConfig` |

`JsonSecrets` 的字段匹配规则：键名小写后含 `secret / apikey / accesskey / token / password / credential / privatekey / aeskey` 之一的非空字符串值都加密（宁可多加密不漏）。解密失败（密钥缺失/轮换）走 lenient 路径返回空串并记 `[crypto]` WARN，不让密文冒充满值。

> **页面不回显**：读接口对密钥打码。`TenantConfigRedaction`（占位符 `***`）负责租户的 Web 搜索 / 解析引擎 / 存储引擎三族配置；更新时 `preserveIfRedacted`——传空串或 `***` 一律保留旧值，前端因此永远拿不到完整 secret。

## 18.3 限流

Embed 公开面的滑窗限流在 `EmbedAuthFilter` 内做三段判定：per-IP 每分钟（渠道配置 `rate_limit_per_minute`）、渠道全局每分钟（`perIp × 20`，下限 120）、渠道全局每日。实现 `EmbedRateLimiter`：`embed.redis-enabled=true`（多副本部署）时判定走 Redis ZSET 滑窗（Lua 原子"清过期 → 计数 → 未满登记"，键 `embed:ratelimit:<windowMs>:<key>`，成员 `毫秒-实例ID-序号` 防同毫秒覆盖），**预算跨实例共享**；Redis 故障回落进程内滑窗；单实例缺省纯本地。启动即验连接（配置成 Redis 却连不上拒绝启动）。认证白名单、`/r/`、IM 回调等其它公开面无通用限流；容器上传面靠 multipart 上限兜底（见 [§18.7](18-安全与治理.md)）。

## 18.4 审计：三条流、只追加

| 流 | 查询入口 | 守卫 |
|---|---|---|
| 空间审计流 | `GET /api/v1/tenants/{id}/audit-log`（`AuditLogController`） | 租户匹配 + Admin+；只看无作用域行（`scope_type=''`） |
| 知识库活动流 | `GET /api/v1/knowledge-bases/{id}/activity` | KB 归属/创建者或 Admin；**只对 JWT 开放**，任何 API Key 能力都不授予审计读取 |
| 平台审计流 | `GET /api/v1/system/admin/audit-log`（`tenant_id=0` 的行） | SystemAdmin + API Key 能力 `system_audit_read` |

写入：`audit_logs` 只追加（仓储只有 `insert` 与保留期 `delete`，无 update）；`AuditLogService.logBestEffort` 尽力而为（写失败只记日志不影响业务响应）。跨模块经 `contract` 的 `AuditWritePort`（`AuditWriteAdapter` 适配）——技能库、Agent 工具/审批等调用方不直连 audit 包；知识库活动由 `WikiActivityAuditRecorder` 等记录；RBAC 拒绝由 `RbacDeniedAuditorRegistrar` 注册进 `RbacInterceptor`。动作常量共 65 个（`contract/.../audit/AuditAction.java`，点分命名空间），实际会写审计的操作包括：成员增删/角色变更/离开、邀请全生命周期、RBAC 拒绝、技能增删改、知识库增删改/克隆/分享、知识与标签增删改、FAQ 导入、数据源增删改与同步结果、向量库生命周期与 OpenSearch 派生资源、系统设置变更/管理员晋升/系统用户与平台 API Key 管理/队列运维、Wiki 内容变更。游标分页（单调 id，`nextCursor=0` 停止）。保留期：`weknora.audit.retention-days`（缺省 90），`AuditLogRetentionRunner` 每天清扫一次。

## 18.5 高危工具人工审批

Agent 工具侧的高危操作（如 MCP 工具调用审批 `POST /api/v1/agent/tool-approvals/{pendingId}`、OAuth 解析确认）走"生成待审项 → 人工批准/拒绝 → 回填执行"的闭环，由 `AgentToolApprovalController` / `McpOAuthController` 承载。细节见 [§11](11-工具技能与MCP.md)。

## 18.6 错误外壳与信息泄露

`platform/.../web/error/GlobalExceptionHandler` 是统一错误面：`BizException` → `AppError` 信封（`{code,message,details}` 或 `@ApiResult` 下的 `{code,message,data}`）；未映射路径保持 `404 text/plain "404 page not found"`；其余未捕获异常走 `handleOther`——**只记日志、对外固定回 500 `"Internal server error"`、`details=null`**，内部异常文案（含异常类名与 message）不出进程。日志侧守卫 `scripts/check-log-exceptions.py` 硬性禁止把 `Throwable` 转字符串写日志（`.getMessage()` / `.toString()` 会丢栈），必须传异常对象；用户输入入日志前经 `LogSanitizer` 消毒（注册的密码刻意不消毒是例外，防"注册成功却登录不上"）。401/403 文案同样刻意收敛：API Key 不存在/撤销/过期统一 `invalid API key`，租户不存在统一 `invalid API key`（不泄露"租户不存在"）。

## 18.7 文件访问与上传限额

`FileProxyController`（`domains/.../storage/controller/`）承载四组鉴权分层各异的文件路由：

| 路由 | 鉴权 |
|---|---|
| `GET /files` | 需登录；不在 `/api/v1` 组内，控制器自带 `AllowFileServeAPIKeyInterceptor`（受限 Key 拒、full-access 与 retrieve 放行） |
| `GET+HEAD /api/v1/files/presigned` | `AuthFilter` noAuth 白名单放行（IM 平台 HEAD 预检契约）→ 免鉴权、**HMAC 自证** |
| `GET /api/v1/files/presigned-preview` | 显式 `DenyAPIKeyPrincipalInterceptor`（403）+ RBAC ADMIN 规则 |
| `GET+HEAD /r/{token}` | 完全无鉴权，短时令牌自证（面向无法带认证头的 IM 客户端） |

上传限额是双层：`application.yml` 的 `spring.servlet.multipart.max-file-size` / `max-request-size` 均为 `60MB`——刻意让 service 层的 50MB 业务校验先触发、给出业务化错误；超出 60MB 的请求由 `TemporaryDocumentController` 的 `MaxUploadSizeExceededException` 处理器转 400 `"request body too large"`。

## 18.8 威胁 → 缓解 → 代码落点

| 威胁 | 缓解措施 | 代码落点 |
|---|---|---|
| 出站请求打内网/云 metadata（SSRF） | scheme 白名单 + 受限主机/后缀/端口 + 直连 IP 与混淆拒绝 + DNS 全解析公网校验 + 双源白名单 | `SsrfGuard` + 各出站客户端 |
| 凭据落库泄露 | AES-256-GCM 字段级加密 + 响应面打码 `***` + 更新面保留旧值 | `CryptoService` / `JsonSecrets` / `TenantConfigRedaction` |
| 跨租户数据越权 | 请求线程身份上下文 + 跨线程显式快照 + SQL 谓词探测 + URL 租户匹配 | `TenantContext` / `TenantScope` / `TenantFilterGuard` / `RbacInterceptor.checkPathTenantMatch` |
| 漏写租户谓词的 SELECT | `enforce` 模式执行期抛异常（fail-loud） | `TenantFilterGuard`（`MybatisPlusConfig`） |
| API Key 权限失控 | 能力维度 default-deny 策略表 + KB 白名单/capabilities + 角色阶梯短路 | `APIKeyGateInterceptor` / `APIKeyRouteAuthorizer` |
| 白名单被路径穿越绕过 | 解码 URI 出现 `..` 段一律 400 | `AuthFilter` 通道 0.5 |
| Embed 匿名面滥用 | Origin 白名单 + 三段滑窗限流 + 渠道启用检查 | `EmbedAuthFilter` / `EmbedRateLimiter` |
| 内部异常信息外泄 | 500 固定文案、日志禁 `Throwable` 字符串化 | `GlobalExceptionHandler` / `check-log-exceptions.py` |
| 操作抵赖 / 拒绝溯源 | 只追加审计表 + RBAC 拒绝落审计（滑窗去重）+ 保留期清扫 | `AuditLogService` / `RbacDeniedAuditorRegistrar` |
| 高危工具被 Agent 直接执行 | 待审项人工批准后才放行（见 [§11](11-工具技能与MCP.md)） | `AgentToolApprovalController` |
