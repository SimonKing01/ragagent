# RagAgent 融合小灵管理能力 MVP 实施清单与验收标准

日期：2026-11-12。状态：实施前方案；业务实现与验收尚未开始。

以 RagAgent 为唯一运行底座，迁入小灵的三员、资料密级、部门用户同步和第三方接口工具管理能力，并统一管理平台模型。首版使用新环境、新数据和本地登录。按阶段交付可核验的结果，第三方接口工具先实现，待其他功能完成后统一测试。

本次交付仅为方案文档，不修改业务代码、配置、数据库，不启动同步、不调用第三方业务接口、不部署。

## 1 已确认的产品范围

| 编号 | 已确认要求 | 实施口径 |
|---|---|---|
| R01 | RagAgent 为基础 | 保留现有 RAG、Agent、模型调用和工具执行体系，按模块适配小灵能力 |
| R02 | 平台级三员 | 系统管理员、保密员、审计员互斥；专职账号与业务账号分离；三员不参与普通问答和业务正文读取 |
| R03 | 部门与工作空间分开 | 部门表示组织结构，工作空间表示业务协作范围；同步部门不等于授予工作空间权限 |
| R04 | 系统管理员所有管理增删改均受审批控制 | 包括账户、部门、角色、密级、模型、系统配置、第三方系统、工具及批量操作；删除、启停、发布、回滚、密码重置也属于变更 |
| R05 | 保密员管理审批开关 | 默认开启；关闭时新申请直接执行但完整审计；禁止自审；关闭开关不自动执行已有待审批申请 |
| R06 | 全部模型统一管理 | Chat、Embedding、Rerank 及现有其他模型类型统一由平台管理；普通用户和租户管理员不得自建模型、接入地址或凭据 |
| R07 | 用户可选开放的聊天模型 | 用户只能选择系统管理员开放且当前可用的聊天模型；Embedding、Rerank 等由系统统一配置 |
| R08 | 部门用户同步复刻小灵现有功能 | 包含连接配置、字段映射、预览、手动和定时同步、对账、人员状态、运行记录及错误明细；不缩减成仅手动同步 |
| R09 | 第三方接口工具先做后测 | 实现 OpenAPI/Swagger 文件导入、工具草稿、发布和执行接入；该功能的单元、模拟、接口和真实联调测试均推迟至其他功能完成后 |
| R10 | 新环境开始 | 不迁移小灵历史账户、文档、会话或凭据；部署目标、端口及资源需在实施前核实 |
| R11 | 本地用户名密码登录 | 用户名无需是邮箱；不做第三方登录或 SSO；组织同步与业务接口接入仍在范围内 |
| R12 | 禁止自助注册 | 本地账户由系统管理员添加；外部账户经受控组织同步产生；关闭页面和后端注册、邀请注册等开户旁路 |
| R13 | 配置初始化三员 | 首次初始化从配置创建三名独立三员；重启不能覆盖已有密码、角色或账户 |
| R14 | 密码复杂度开关 | 开启时必须同时包含大写、小写字母；关闭时取消字符组合要求，但密码非空；不额外强制数字或特殊符号 |
| R15 | 沿用小灵密级规则 | 公开、内部、秘密、机密、绝密；知识库设最高密级；上传定密，入库后密级固定，纠错采用受控删除后重传 |

密码复杂度开关由系统管理员维护并受审批控制。规则用于开户、重置和修改密码；开启后不立即阻断已有账户登录。密码始终哈希存储。具体默认开关值在初始化配置中明确，不由缺失配置随意推断。

### 1.1 MVP 开放范围

首版交付管理后台、本地业务登录、知识库文档问答和受控第三方查询工具。查询工具须按真实副作用分类，不能简单将 GET 视为安全、POST 视为写入。

第三方写入类工具、第三方登录/SSO、小灵历史数据迁移、拖拽工作流、Office 制品能力迁移、全套评测发布平台迁移不在首版交付范围。

RagAgent 已有 Wiki、记忆、图谱、IM、Embed、API Key 等路径逐项登记：需要开放的路径完成相同权限约束；尚未适配的路径在服务端禁止访问受控资料。不能仅隐藏菜单，也不能以 MVP 为理由保留权限旁路。

## 2 全局行为约束

### 2.1 三员及审批

| 主体或状态 | 允许行为 | 禁止行为 |
|---|---|---|
| 系统管理员 | 查看治理所需元数据，提出管理变更；开关关闭时经统一执行入口生效 | 自审、自行修改审批开关、直接改生效数据、绕过审批读取业务正文 |
| 保密员 | 审批或驳回申请；切换审批开关并留审计 | 审批本人申请、修改申请内容后沿用原批准、读取模型密钥或业务正文 |
| 审计员 | 查询授权范围内的审计和执行结果 | 修改配置、审批申请、改变审计记录、读取凭据或业务正文 |
| 业务用户及租户管理员 | 按工作空间权限、密级及工具授权使用业务能力 | 管理平台模型、提升自身密级、借租户 Owner 身份绕过治理权限 |
| 审批开启 | 新变更固定对象、动作、参数和前置版本，待批准后执行 | 审批前修改生效数据；批准 A 后执行 B |
| 审批关闭 | 新申请记录跳过人工审批的事实，执行相同校验与审计 | 跳过身份、互斥、末位三员保护、密级、参数和并发校验 |

所有系统管理员管理写入口，包括草稿保存、导入落库、单条与批量入口，都须纳入操作清单。浏览器内编辑和无副作用预览可不产生生效变更；服务器持久化管理数据不能借“草稿”绕开统一变更入口。审批记录、执行状态和审计自身的系统写入无需递归申请审批。

首次三员初始化是一次性引导流程，在尚无三员时完成；不成为后续配置修改的长期免审批入口。保密员切换审批开关直接生效并记录前后值、操作者和时间。

批准时和真正执行前均校验当前操作者权限、目标状态及申请版本；过期或冲突申请不覆盖新数据。重复批准、重试和并发处理不得重复执行同一变更。

含密码或凭据的变更只向审批人和审计展示脱敏元数据；执行所需秘密受保护保存，不能因要求“固定申请内容”而将明文秘密写入申请详情、差异或日志。

### 2.2 模型统一管理

- 平台维护全局模型目录、默认值、可用状态、能力和凭据；不依赖某个普通租户的私有模型作为全局目录。
- 前端仅投影当前用户可用的聊天模型，不下发 Key 等秘密。现有用户/租户模型管理写接口同样收口。
- Agent 配置、知识库配置、直接 API 和后台任务均只能引用获准模型，不接受调用方覆盖地址、凭据或私设 Embedding/Rerank。
- 模型停用后，新调用及待执行任务重新检查状态；不得因缓存、重试或备用模型机制回到被禁用接入。
- 首版配置一个生效的 Embedding 和 Rerank 选择。Embedding 维度或模型改变必须识别索引不兼容；未完成重建不得将新向量与旧索引混用。
- 启动配置、内置模型对账、默认模型回退和管理员页面采用同一治理规则。现有 `builtin_models.yaml` 的启动新增、更新和软删行为不得成为免审批旁路。

### 2.3 资料与工具授权

允许读取需同时满足：可信主体有效、现有租户/资源权限满足、密级满足、来源及索引状态有效。密级不代替原有权限，部门归属不自动授予全部资料。

检索在返回正文前过滤授权范围；关键词、向量、父块、邻块和工具直读一致。空授权集合必须返回无结果，不能解释为无限制。下载、图片、签名链接、历史上下文和派生内容均不能绕过当前来源授权。

工具发布审批与会话中的执行确认分别建模。第三方系统服务账号权限不能直接视为当前用户权限；需要用户委托身份时，缺失委托应拒绝，不能静默换用权限更大的服务账号。

## 4 分阶段实施清单

阶段顺序为 P0 → P1 → P2 → P3 → P4 → P5 → P6。P3 只完成接口工具实现及必要编译检查，不执行该功能测试；在 P6 集中验证。各阶段清单当前均未完成。

### P0 规则和工程基线

- [ ] P0-01 固定 RagAgent 基线与小灵参考文件；盘点现有管理写入口、模型配置入口、注册和外部认证入口。
- [ ] P0-02 确定身份、审批、模型、组织、密级、外部工具的数据关系与跨模块契约。
- [ ] P0-03 建立三员操作矩阵、受控数据访问路径清单和入口处置表：适配、服务端关闭、只读。
- [ ] P0-04 明确定时同步的审批语义及小灵同步等价表，解决第 8 节 D01；选择首版检索后端。
- [ ] P0-05 定义隔离测试环境、虚构账户与资料、真实联调输入；保存原有问答和本地登录的可复现基线。

交付：数据关系、契约、操作矩阵、同步等价表、环境及测试计划。此阶段不导入真实资料、不连接第三方业务系统。

### P1 本地账户和三员审批

- [ ] P1-01 从配置一次性创建三名三员；校验用户名不重复、角色互斥，初始化中断可安全重试。
- [ ] P1-02 实现用户名密码登录；移除邮箱必填约束；关闭自助注册、邀请注册、OIDC/SSO 及其他可创建账户的旁路。
- [ ] P1-03 系统管理员创建本地业务账户；实现启停、密码重置、角色及密级变更申请；旧会话及时失效。
- [ ] P1-04 实现密码复杂度开关，在开户、重置、修改密码、外部账号初始密码路径统一执行。
- [ ] P1-05 实现三员隔离、末位保护、审批开关、申请/批准/驳回/执行/失败状态和审计。
- [ ] P1-06 既有管理员管理写接口逐项接入；尚未接入的写入口服务端拒绝；API Key 不得替代三员身份绕过。
- [ ] P1-07 完成本阶段前端、接口与独立权限审查，执行对应阶段验收。

交付：可配置初始化的三员后台、本地业务账户、统一管理变更流程。首版不承诺免密码或第三方登录。

### P2 全局模型管理

- [ ] P2-01 建立平台模型目录和按能力的系统选择，迁移现有模型管理入口权限。
- [ ] P2-02 管理员维护模型和可用范围，经审批生效；用户仅获取可用聊天模型及默认值。
- [ ] P2-03 禁止用户及租户管理员添加、修改、删除模型，禁止 Agent/知识库/接口传入自定义地址或凭据。
- [ ] P2-04 收口启动配置对账、缓存、任务模型快照、备用模型和调用入口；处理 Embedding 索引兼容。
- [ ] P2-05 完成前端及验收；用批准的测试模型分别验证 Chat、Embedding、Rerank 调用和配置归属。

交付：全局统一模型配置与业务使用闭环。模型选择的权限配置只归平台治理，不替换现有供应商调用实现。

### P3 第三方接口工具实现

- [ ] P3-01 实现第三方系统、凭据、可见范围和工具草稿；复用统一变更、审批及审计入口。
- [ ] P3-02 实现 OpenAPI/Swagger 文件解析、操作选择、参数与返回字段映射、命名冲突和逐项导入报告。
- [ ] P3-03 根据实际样本确定支持版本、JSON/YAML 和 Schema 子集；不支持的引用、参数或响应结构明确报错，不能生成看似成功的工具。
- [ ] P3-04 工具草稿经审批生成生效版本；停用后停止新调用；导入或重新导入不能自动发布。
- [ ] P3-05 接入现有工具注册和执行契约，支持受控查询工具，完成身份、参数、凭据、密级及结果处理。
- [ ] P3-06 实现工具管理前端，登记延后测试清单；功能保持未开放状态，等待 P6 验证。

交付状态只允许为“已实现、未验证”。本阶段不执行工具单元测试、模拟调用、浏览器工具流程或真实联调，不借服务启动、健康检查或自动发现实际访问第三方工具。允许源码检查与必要编译；构建需明确跳过该功能测试。

P3 提前使用 P0 约定的身份和密级契约；P5 尚未提供有效授权时默认拒绝执行，不以临时放行完成接线。

### P4 复刻小灵部门用户同步

- [ ] P4-01 实现部门树、用户部门、外部标识、身份源配置和字段映射，保留本地与外部账号区分。
- [ ] P4-02 复刻部门两遍对账与父子关系处理、源根节点处理及现有映射行为。
- [ ] P4-03 复刻预览、手动/定时同步、运行统计、分页历史、逐项事件和部分失败状态。
- [ ] P4-04 复刻用户创建、姓名/部门更新、在岗启停、会话吊销、源缺失逻辑删除及重新出现后的恢复行为。
- [ ] P4-05 保护本地密码、已有密级、三员身份和历史关联；处理用户名冲突、重复外部 ID、重复源登录名。
- [ ] P4-06 按 D01 确定的规则接入手动与定时任务审批；约束批次并发与重复执行。
- [ ] P4-07 用固定源数据夹具验收同步行为，真实身份源的契约和联调单独留证。

复刻基准：小灵只有在源接口成功、当前批次无错误时，才对源中缺失的外部业务账号进行逻辑删除并吊销会话；源身份重新出现则恢复原账号，保留密码、密级及历史关系。不得沿用早先“改成仅停用”的建议替换已确认的复刻要求。若需增加空源或异常缩量保护，应在等价表中记录差异并确认。

### P5 文档密级和问答授权

- [ ] P5-01 建立小灵密级字典、用户密级、知识库最高密级、文档定密及校验。
- [ ] P5-02 覆盖文件、网页、手工内容、FAQ、数据源等实际开放的入库入口，以及复制、移动和重解析；无明确密级不按公开兜底。
- [ ] P5-03 列表、计数、搜索、摘要、分块、预览、下载、图片和签名链接采用当前资源授权。
- [ ] P5-04 首版检索后端的关键词、向量、父块、邻块和图扩展遵守授权范围，重排和生成前重验。
- [ ] P5-05 历史回答、上下文、引用、缓存、Wiki、记忆和工具结果落实来源与密级约束；未适配路径服务端拒绝受控访问。

## 7 新环境和交付边界

- 不复用或修改小灵已有数据库、端口、运行实例和凭据；实施前确认独立资源归属。

- 不顺带升级 RagAgent 的 Spring Boot 或替换前端设计体系；小灵代码按现有依赖适配。
- 首版不迁移小灵旧数据，也不把已有生产系统切换计入本次文档授权。
- 功能开关用于限制开放范围，不能作为关闭已有密级、授权或审计的捷径；只有已明确的审批和密码复杂度开关改变对应行为。
