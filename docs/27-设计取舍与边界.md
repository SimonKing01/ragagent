# 27. 设计取舍与边界

每条都是"做了什么 + 代价是什么"。架构不是免费的，读代码时如果觉得"为什么不多做一步"，先查这里。

## 27.1 架构与边界

- **契约层纯 JDK**：跨模块公开类型不带任何框架便利（分页、注解全手写），换取"任何模块零成本依赖契约 + 前端契约同一来源"。
- **模块是 Maven 的，Bean 图是按包扫的**：`agent-engine` 的 Bean 靠根包组件扫描发现（编译图看不见运行图）；代价是包根必须待在 `com.ragagent` 之下，挪动会静默失效。
- **探测代替 SQL 自动改写**：租户隔离与软删不自动改写 SQL，而是"仓储手写条件 + 插件探测 fail-loud"；代价是新增无谓词查询在 `enforce` 档执行期红，而不是被自动改对。
- **棘轮而非一步清零**：存量违例（包环、超长文件/方法、命名口径）登记基线，拦增量、随清理收紧；代价是基线文件本身要维护。

## 27.2 模型与检索

- **厂商差异只做两层**（协议级 Anthropic + 参数级 12 个 `ProviderAdapter`），不做 per-provider 传输类：新增厂商成本极低；代价是未适配厂商拿不到 thinking/参数整形，需用调试端点回归。
- **并发治理只打后台流量**：摄入风暴不影响交互延迟；代价是交互式调用本身不受闸门保护，可能击穿供应商限流。
- **RRF 按秩融合**而非分数加权：免疫各引擎分数量纲差异；代价是丢失绝对分数、并列分数多（靠 chunkId 决序保证确定性）。
- **多引擎可混用**（按知识库绑定不同向量库扇出）：代价是跨引擎分数必须归一、多知识库被强制共用同一嵌入模型（400 闸门）。
- **检索失败语义收敛为哨兵**（"没搜到"不是异常）：异步任务不会把一次性故障变成永久丢单；代价是引擎内部错误只进结构化日志，用户只见笼统文案。

## 27.3 问答与 Agent

- **流状态全部用 append-only 事件承载**：续流 / steer / 审计复用同一事件源；代价是消费方必须自己扫事件判定终态。
- **一轮问答不包大事务**：拆成"同事务写两行 → 零库写流式 → CAS 收尾"；代价是终态一致性靠两层 CAS 而非数据库约束。
- **插件链用注册序闭包**：加插件零改框架；代价是执行顺序在静态调用图里不可见，靠脚本生成的管线表 + 完整性测试兜底。
- **串行/并行检索共享同一插件实例**：省一次装配；代价是这两个插件必须永远无状态。
- **引擎跨轮无状态**（历史每轮由会话域重建传入）：可重放、无缓存失效；代价是每轮一次历史装载与全量重建。
- **MCP"按需目录"**：省上下文、隔离未授权服务；代价是真实调用前多一次 discover/describe 交互。
- **工具审批等待者驻留内存 + Redis 广播决议**：零轮询延迟；代价是无 Redis 部署只能单副本。

## 27.4 知识生产与任务

- **主入库链路不做跨实例队列**（进程内虚拟线程 + 重启复位补投）：单机零依赖；代价是多副本任务亲和上传副本、重启丢在飞任务——富化子任务才走 Redis。
- **每阶段独立提交、不包大事务**：解析/向量化是长外部调用；代价是中间失败要靠"失败只清本次产物 + 代次 CAS"补偿。
- **取消是 CAS 抢行不是中断**：实现简单；代价是长阶段要到检查点才停。
- **摘要旁路 finalizing 计数**：一个慢 LLM 调用不会把文档钉在 `finalizing`；代价是终态判定多一套字段。
- **连接器目录与注册表分离**（17 项目录 vs 9 个实现）：前端可展示"即将支持"；代价是消费方必须按注册表判能力。

## 27.5 平台面

- **注册即建个人空间并授 owner**：注册即可用；代价是空间数量随注册线性增长（自助创建另有配额底座）。
- **RBAC 对机器主体短路**：角色阶梯管人、API Key 走 default-deny 能力表；代价是同一操作维护两张策略表，漂移由守卫抓。
- **审计只追加 + 尽力而为写**：审计失败不影响业务响应；代价是极端情况下审计行可能缺失。
- **凭据加密自描述**（`enc:v1:` 前缀、无前缀视为历史明文）：启用加密不停机迁移；代价是密钥丢失后 lenient 读空串。
- **可选 Bean 的两面性**：`getIfAvailable()` 多数是"缺了就退化"，个别路径是"缺了就炸"（把配置错误提前到启动期）——读代码时必须逐点核对，不能靠猜。
- **契约用手写前端类型 + 金片签字兜底，而非 codegen**：省一套生成管线；代价是后端改字段前端照样编译通过，必须靠金片对账把静默漂移变成必红项。

## 27.6 已知边界（诚实清单）

- **`PRIMARY` 约束**：外部依赖（Redis 队列 / 流管理器 / Langfuse / Neo4j）配置成启用但连不上时，启动**失败**而非降级——这是刻意的 fail-loud，排障时不要找"为什么没自动切换"。
- **效果非确定性**：测试只保工程正确性；模型/提示词变更后应使用模型调试端点与真实链路抽检做回归。
- **仓库零密钥**：全部凭据环境变量或 AES 加密落库注入；`.env` 不入库。
- **历史命名**：`weknora.*` 配置前缀、库名、`knowledage-base` 前端包名均为历史命名（上游致谢 WeKnora），见 [§29](29-术语表.md)。
