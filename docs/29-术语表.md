# 29. 术语表

每条一句定义；带落点的详见对应章节。历史命名单列在最后。

## 业务与检索

| 术语 | 含义 |
|---|---|
| 知识库 / KB | 一组文档、分块、索引配置的集合；检索与问答的作用域（[§8](08-知识生产-文档入库管线.md)） |
| 文档 / knowledge | 上传到知识库的一份原始文件；重解析有"代次"（`parse_attempt`）乐观锁（[§8](08-知识生产-文档入库管线.md)） |
| 分块 / chunk | 文档切分后的检索单元；`parent_text` 类型是给长上下文用的父块（配置已实现、主链路未接线） |
| env-store / DB-store | 环境级注册的共享检索引擎 / 控制台注册并绑定给知识库的向量库实例（[§7](07-检索引擎.md)） |
| RRF | 按店内名次的倒数秩融合：缺省 k=60、向量权重 0.7、关键词权重 0.3（[§7.4](07-检索引擎.md)） |
| 重排 / rerank | 对召回结果二次打分排序；可配模型与阈值（[§6.5](06-模型层.md)、[§9.5](09-RAG问答管线.md)） |
| 管线 / 阶段 / 插件 | 问答按 14 个事件阶段推进，插件按注册序串成链（[§9](09-RAG问答管线.md)） |
| 金片 / golden | 归一化断言的 HTTP 响应样本；有意变更才重录（[§24.3](24-测试体系与质量门禁.md)） |
| Wiki 链接图 | Wiki 页面 `[[slug]]` 引用形成的入链/出链/孤儿图，与 Neo4j 实体图谱是两回事（[§14](14-Wiki与知识图谱.md)） |
| 记忆主体（subject） | 工作区里的一个人/访客，`Type:ID` 从请求上下文推导、永不来自客户端传参（[§13](13-记忆体系.md)） |
| 蒸馏 / 墓碑 / 亲和度 | 记忆的异步抽取 / 被拒绝话题的指纹 / 用户反复引用文档的计数（[§13](13-记忆体系.md)） |

## Agent 与工具

| 术语 | 含义 |
|---|---|
| ReAct | 思考 → 调工具 → 观察的循环；自然停 + 纯文本为终态（[§10](10-Agent引擎.md)） |
| steer | 运行中插话：排队在流管理器独立子列表，当轮注入或由后续轮消化（[§5.4](05-一次请求的全流程时序.md)、[§10](10-Agent引擎.md)） |
| live run | 会话当前正在生成的 assistant 消息，排他；重复开跑 409（[§12](12-会话流式输出与SSE.md)） |
| 无头监控 | 客户端断开后流泵降级为低频监控，取消能力不随连接消失（[§12.3](12-会话流式输出与SSE.md)） |
| 三级注入 | 技能的渐进加载：元数据目录 → 完整指令 → 附属文件（[§11.2](11-工具技能与MCP.md)） |
| 按需目录 | MCP 不预连上游不广告全量 schema，模型经 `discover_mcp_tools` 精确拉取（[§11.3](11-工具技能与MCP.md)） |
| fail-close | 审批策略查询失败时仍要求人工审批（[§11.4](11-工具技能与MCP.md)） |
| first-wins 注册 | 工具注册表对同名工具保留先到者，防借名劫持（[§10](10-Agent引擎.md)） |

## 平台与工程

| 术语 | 含义 |
|---|---|
| 租户 / 空间（tenant） | 数据隔离边界；用户经成员关系归属，可属多个空间（[§17](17-多租户认证与RBAC.md)） |
| tenantless | 无活动空间的会话态，只有身份级路由可用（[§17](17-多租户认证与RBAC.md)） |
| 角色下限 / 第二层判定 | 路由的最低角色；通过后还有所有权 / API Key 范围 / 渠道签名（[§17.5](17-多租户认证与RBAC.md)） |
| 系统管理员 | `users.is_system_admin` 平台级标记，非空间角色（[§17.5](17-多租户认证与RBAC.md)） |
| 组合根（composition root） | `:boot` 的 `com.ragagent.config`，跨模块 Bean 唯一集中地，只出不进（[§3.2](03-整体架构.md)） |
| 端口（Port） | `:contract` 里的跨模块接口，实现侧唯一；复合端口聚合多个子端口（[§4.1](04-模块UML类图.md)） |
| 装配点 | 登记在案的 `@Configuration`（组合根 8 + 域内 11 + 模块内 4）（[§3.2](03-整体架构.md)） |
| 棘轮（ratchet） | 基线登记存量违例：基线外新增即红、清理后收紧，"只许减不许增"（[§24.4](24-测试体系与质量门禁.md)） |
| 守卫（guard） | 48 条架构/契约检查，CI 与本地同一入口（[§24.4](24-测试体系与质量门禁.md)） |
| 启动期快照 | 装配期一次性写入进程级只读值（AES/SSRF/语言/存储）（[§3.2](03-整体架构.md)） |
| 发布票 / 会话票 | Embed 渠道的站点票据 / 访客短期票据（30 分钟）（[§15.2](15-渠道接入IM与网页嵌入.md)） |
| publish token 换票 | 浏览器端用 `em_` 票换 `ems_` 短期票，避免站点凭据公开（[§15.2](15-渠道接入IM与网页嵌入.md)） |
| docreader | 独立容器的文档解析 gRPC 服务（[§8.3](08-知识生产-文档入库管线.md)） |
| 代次（parse_attempt） | 重解析乐观锁列；旧尝试迟到写 0 行退出（[§8](08-知识生产-文档入库管线.md)） |

## 历史命名（读代码时忽略语义、只作标识）

- **WeKnora**：本项目参考/复用的上游 Go 项目；`weknora.*` 配置前缀、`DB_NAME` 缺省值等都是历史命名，不是当前产品概念。前端对外全局对象已改名。
- **knowledage-base**：前端包名里的历史拼写错误（正确是 knowledge），仅作标识。
