# 《RagAgent 详细技术文档》

> 适用项目：**RagAgent · 企业级 RAG + Agent 平台**（单仓多模块：7 个 Maven 模块 + Vue 3 控制台 + 独立交付的 docreader 容器与 MCP 参考服务）｜ 协议：MIT
> ｜ 技术栈：JDK 21（虚拟线程）· Spring Boot 3.3 · MyBatis-Plus + PostgreSQL（ParadeDB/pgvector）· Redis 7
> ｜ 质量基线：全量测试 5,252 条（0 失败；环境相关用例可跳过但需登记理由）、1,339 份契约金片、48 条架构守卫与 CI 五 job 同频
> ｜ 这套文档与代码同步受守卫约束：出现的类名、路径必须真实存在（`scripts/check-reference-truth.py`）。

> 文中所有图均为 Mermaid，GitHub 原生渲染；类名、方法、配置键均与源码一致。上游致谢：[Tencent/WeKnora](https://github.com/Tencent/WeKnora)。

---

这套文档面向两类读者：

- **初学者**：按 [§1 总览](01-项目总览.md) → [§3 整体架构](03-整体架构.md) → [§5 一次请求的全流程时序](05-一次请求的全流程时序.md) → [§9 RAG 问答管线](09-RAG问答管线.md) 的顺序建立全局认知，再按需展开。
- **资深使用者**：直接看 [§4 模块 UML 类图](04-模块UML类图.md)、[§22 配置体系](22-配置体系.md)、[§25 HTTP 接口速查](25-HTTP接口速查.md) 与 [§26 扩展点总表](26-扩展点总表.md)。

> 文中所有图均为 Mermaid，GitHub 原生渲染；类名、方法、配置键均与源码一致，关键数字都可在 [§29](29-术语表.md) 术语表对应的守卫与脚本里复核。
