# 22. 配置体系（含配置项总表）

## 22.1 配置从哪来、优先级如何

- **`boot/src/main/resources/application.yml`** 是唯一的 Spring 配置文件——目录下没有 `application-prod.yml` 之类 profile 分文件（已核实）。所有可外部化的键都是 `${ENV:default}` 形式，缺省值即 dev 值。
- **`.env`（模板 `.env.example`）**：dev 起服脚本 `scripts/dev-env.sh` 按 key 读取（不整份 source），注入 `scripts/java-server-up.sh` 等进程环境；容器部署则由 `deploy/docker-compose.prod.yml` / `env.prod.example` 注入。
- **数据库系统设置**：`system_settings` 表的合法键由 `SystemSettingRegistry`（17 条）登记，解析顺序为 **DB 行 → ENV → 内置默认**（`SystemSettingService` 三层解析；每请求直读 DB，无跨副本缓存）。运行期可调并已接副作用的键：`ssrf.whitelist`（更新即推 `SsrfGuard.reloadWhitelist`，含 `SSRF_WHITELIST_EXTRA` 合并）、`model.max_concurrency`（推并发闸门）、`sandbox.docker_enabled`；应用就绪时还会把 DB 白名单预载进 `SsrfGuard`，避免重启后 env 白名单覆盖 UI 保存值。
- **`config/builtin_models.yaml`**（`BUILTIN_MODELS_CONFIG` 指定，缺省 `./config/builtin_models.yaml`，文件不存在 = no-op）：启动时按声明对账 `models` 表。细节见 [§6](06-模型层.md)。
- 另有 `LANGFUSE_*`（`LangfuseEnvProperties`）、`NEO4J_ENABLE/URI/USERNAME/PASSWORD`（`Neo4jProperties`）、`SSRF_WHITELIST`/`SSRF_WHITELIST_EXTRA`（`SsrfWhitelistProperties`，env 名经 Spring 松散绑定映射到 `ssrf.*`）等族，不在 `application.yml` 出现、按各自属性类绑定。

## 22.2 绑定与守卫

- **绑定白名单**：见 [§3.2](03-整体架构.md)——`@ConfigurationPropertiesScan` 只扫 10 个包，白名单外的属性类静默不生效，由 `ArchitectureRulesTest` 的"属性类必须被扫描覆盖"规则断言。
- **禁止裸读 `System.getenv`**：`ArchitectureRulesTest` 有一条"主代码不得调用 `System.getenv`"的规则（两种重载都禁）。合法取值路径只有四类：`@ConfigurationProperties` 注入、域查找面（`*EnvLookup`，如 `RetrievalEnvLookup` / `StorageEnvLookup`）、启动期值快照（`RuntimeSnapshotWiring` 的 `install*`，且另一条规则规定只有 `*.config` 装配层可调用）、全局 `AppEnvLookup`——后者由 `AppEnvLookupEnvironmentPostProcessor`（`EnvironmentPostProcessor`）在**所有 bean 实例化之前**挂到 Spring `Environment` 上，取值实时、无陈旧快照。
- **启动期只读快照**：`RuntimeSnapshotWiring` 在装配期一次性写入语言默认值、上传限额、AES 密钥（`CryptoService.installAesKey`）、SSRF 白名单、本地存储根与存储类型；之后整进程只读。SSRF 白名单是唯一例外通道（`SsrfGuard.reloadWhitelist` 运行时调谐）。

## 22.3 配置项总表

以下每一行均在 `application.yml` 或 `.env.example` 核实过，缺省值照抄原文。

**服务与端口**

| 环境变量/配置键 | 缺省值 | 说明 |
|---|---|---|
| `SERVER_PORT` | `8080` | HTTP 监听端口（dev 惯例 8083，见 `.env.example`） |
| `SERVER_HOST` | `0.0.0.0` | 绑定地址 |
| `SPRINGDOC_ENABLED` | `false` | API 文档（`/scalar` 与 `/v3/api-docs`）开关，生产保持关 |
| `CAPABILITY_REPORT_ENABLED` | `true` | 起服能力报告（检索/JWT/存储/Redis/流管理器摘要） |
| `LOG_LEVEL` | `INFO` | `com.ragagent` 日志级别 |

**数据库**

| 环境变量/配置键 | 缺省值 | 说明 |
|---|---|---|
| `DB_HOST` | `localhost` | PostgreSQL 主机 |
| `DB_PORT` | `15432` | PostgreSQL 端口（容器映射；镜像内 5432） |

**Redis**

| 环境变量/配置键 | 缺省值 | 说明 |

**认证与密钥**

| 环境变量/配置键 | 缺省值 | 说明 |
|---|---|---|
| `SYSTEM_AES_KEY` | 无（必填） | 恰 32 字节；模型凭证加密/临时文档/租户隔离族共用；建库后不可轮换 |
| `JWT_SECRET` | 不设则启动随机 32 字节 | JWT HS256 签名密钥；随机 ⇒ 重启后全员掉登录 |

| 环境变量/配置键 | 缺省值 | 说明 |
